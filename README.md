# my-life-system-skills

Personal Codex skills for planning, building, reviewing, testing, memory, research, and knowledge workflows.

## Codex Sprint Flow

For substantial software work, prefer this sequence:

1. `product-office-hours` - shape product intent and narrow the useful wedge.
2. `code-explorer` - inspect the codebase and gather patterns.
3. `plan-eng-review` - produce an Engineering Contract and test matrix.
4. `code-dev` or `frontend-design` - implement against the contract.
5. `debug-investigator` - reproduce and root-cause failures before fixing.
6. `code-review` - perform static review for correctness and simplicity.
7. `code-testing` - run tests and evidence-based browser QA.
8. `self-evolving-agent` - orchestrate the loop, reflect, and replan when needed.

## Memory Policy

`m-flow-memory` is used as storage and retrieval. Codex should manually summarize and decide what to write; M-flow should not be used as the default summarizer unless explicitly requested.
