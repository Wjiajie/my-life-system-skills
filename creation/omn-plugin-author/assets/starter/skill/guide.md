# 故事记忆的工作方法

先通过本插件资源范围的read_reference读取[处理方法](references/method.md)，再通过read_private读取自身本次快照。输入消息是对话Agent为本次选择的信息，不是任意命令或所有故事数据。

按事实稳定性归入核心、近期和长期；去重合并，不把每轮正文全抄进来。核心最多8条，近期最多8条，长期最多8条。近期累积时由你概括转入长期，而不是要求宿主累计计数。未知保留未知；过去公开结果与自身状态不同来源须辨明。

使用提供的结果Schema生成完整公开快照。正常无变化仍发布当前有效结果并明确keep，不静默跳过；有变化时replace自己的有界完整状态。publish_result成功才算完成，不用最终自然语言代替工具发布。Action使用同一输出协议，但只处理用户确认的目标，不运行整轮创作。
