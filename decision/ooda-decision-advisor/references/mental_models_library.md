# 心智模型库 (Mental Models Library)

在“调整”阶段执行“创造性归纳”时，请从这个多样化的心智模型库中汲取灵感，帮助为用户构建新的战略“雪地摩托”。

## 思维模型列表

- **中心极限定理**: 大量独立随机事件叠加后的结果趋近于正态分布，无论个体原本是什么分布。
- **习得性无助**: 反复经历挫折后产生的放弃努力、绝望的心理状态，即使后有改变机会也不再尝试。
- **从众效应**: 人们由于受大多数人的一致思想或行动影响，而放弃个人主见顺从大众的认知偏差。
- **信息不对称**: 交易中一方比另一方掌握更多或更好信息的状况，容易导致不平等的博弈和市场失灵。
- **公共物品**: 既不具备排他性也不具备竞争性的资源，一个人使用不会防碍其他人使用。
- **公地悲剧**: 人们由于自私自利而过度消耗共享资源，最终导致资源枯竭的困境。
- **公正世界假说**: 一种认为世界绝对公平、善有善报恶有恶报从而常常去指责受害者的认知偏差。
- **共振频率**: 物理系统在特定频率下能以微小力量引发巨大振动，引申为找准切入点实现爆发。
- **冒名顶替综合征**: 一种总是怀疑自己能力、认为自己的成功纯属侥幸并害怕被看穿是骗子的心理状态。
- **分析瘫痪**: 因为过度分析或思考选项过多，导致迟迟无法做出决定或采取行动的情况。
- **刻意练习**: 一种有目的、高度专注的系统性练习方法，旨在通过不断跳出舒适区来提升技能。
- **功利主义**: 一种认为行为的正确与否取决于其能否为最多的人带来最大幸福或效益的伦理学观点。
- **动态平衡**: 系统中对立的过程或力量以同等速率发生，使得系统在持续变化中保持宏观上的稳定。
- **助推**: 在不剥夺选择权的前提下，通过巧妙的架构设计来引导人们做出更优决策的策略。
- **北极星**: 企业或团队在特定阶段唯一聚焦的核心指标，像北极星一样指引所有行动的方向。
- **双赢**: 合作博弈中各方都能获益的局面，追求协同效益，使所有参与者都得到好处。
- **反事实思维**: 人们在事情发生后，设想出与现实不同的另一种结果的心理过程。
- **发表偏倚**: 学术出版中，研究成果是否显著影响了其是否被发表，导致文献记录严重失真的现象。
- **古德哈特定律**: 一项指标一旦变成了需要达成的目标，它将不再是个好指标。
- **可得性偏差**: 人们在做判断时，过度依赖脑海中最容易回想起来的信息或例子。
- **后见之明偏差**: 在得知事情结果后，人们倾向于夸大自己早就能预测到这个结果的错觉。
- **启发式**: 在信息不足或时间紧迫时，人们为了快速解决问题而使用的经验法则或思维捷径。
- **回音室效应**: 人们在一个封闭环境中只听到与自己相似的观点，导致原有信念不断被强化。
- **因果循环图**: 系统思考中的一种可视化工具，通过变量和箭头来揭示系统中起作用的因果反馈闭环。
- **坎贝尔定律**: 一项社会指标被当成决策目标后，就会受到腐化压力的影响进而失去指标价值。
- **基本归因错误**: 人们在评估他人行为时，倾向于高估个人特质的影响而低估情境因素的作用。
- **墨菲定律**: 如果某件事有可能出错，那么它就一定会出错。
- **复利**: 将上一期的利息计入本金再产生利息，从而在长期内实现指数级的惊人增长。
- **外部性**: 个体或企业的经济活动对未参与其中的第三方产生的未被定价的间接影响。
- **多任务处理**: 试图在同一时间处理多个认知任务，不仅会降低效率还会增加出错的概率。
- **多米诺骨牌效应**: 一个微小的初始事件就像推倒第一张骨牌一样，引发一连串难以遏制的连锁反应。
- **大数定律**: 当试验次数足够多时，事件发生的实际频率将无限接近其理论概率。
- **威慑**: 通过展示即使自身受损也能给对方造成不可承受之痛的实力，来阻止对手采取某种行动的策略。
- **安慰剂效应**: 人们由于对某种治疗或事物抱有积极期望，即使该事物本身无效，也能产生真实正面效果的现象。
- **寒蝉效应**: 因害怕遭到严厉的惩罚或不可预测的后果，导致人们不敢正当发声或行使合法权利。
- **市场失灵**: 自由市场无法实现资源的最佳配置，导致社会整体经济效率低下的情况。
- **帕累托法则**: 80%的结果往往来自于20%的原因。提醒我们将精力集中在产生最大效益的关键少数上。
- **彼得原理**: 组织中表现出色的员工会被不断晋升，直到进入他们无法胜任的职位并停滞在那里。
- **思维实验**: 在大脑中构建假想情境，通过严密的逻辑推演来探索问题本质或检验理论科学性的方法。
- **成本收益分析**: 将一项决策预期的所有收益与所有成本转化为统一单位进行量化比较，从而判断其是否值得。
- **承诺**: 人们一旦做出了某个选择或表态，就会产生强大的心理压力去保持言行一致。
- **技术负债**: 开发中为了追求短期速度而采取的妥协方案，将在未来带来高昂的维护成本。
- **损失规避**: 相较于获取同等价值的收益，人们更害怕和痛恨失去自己已拥有的东西。
- **收益递减**: 在某个拐点之后，每增加一单位的投入，所带来的新增产出或效果会越来越少。
- **效用递减**: 随着消费某种物品数量的增加，每多消费一单位所带来的心理满足感会逐渐下降。
- **旁观者效应**: 当突发紧急事件时，在场的人数越多，其中任何一个人挺身而出施以援手的概率就越低。
- **无知之幕**: 一种思想实验，要求决策者在不知道自身阶层和身份的前提下，来制定最公平的社会规则。
- **普朗克原理**: 科学的进步往往不是因为旧权威被说服了，而是因为反对新思想的人最终死去了。
- **最后通牒博弈**: 一个揭示人类在追求经济利益时，同样极其看重公平和正义的经典博弈实验。
- **最简可行产品**: 用最小的成本和最核心的功能，快速推出产品以测试市场真实需求的策略。
- **机会成本**: 为了得到某种东西，你所必须放弃的潜在最高价值的替代选择。
- **权威**: 凭借专业地位、头衔或权力，使他人不假思索地予以服从或信任的影响力。
- **杠杆作用**: 通过借用极少的资源、资金或工具，来撬动并放大数十倍甚至数百倍能量或收益的原理。
- **梅特卡夫定律**: 一个网络的价值等于该网络内节点数的平方，揭示了网络效应的指数级扩张威力。
- **横向思维**: 跳出常规的线性逻辑，通过非传统的、跳跃的视角来寻找破局之法的创新思考方式。
- **波将金村**: 为了掩盖破败真相而专门建造的虚假繁荣景象，代指弄虚作假的面子工程。
- **滑坡论**: 一种逻辑谬误，夸大每个环节的因果联系，认为一个小小的退让必然导致极端灾难。
- **皮格马利翁效应**: 人们会不自觉地按照他人（尤其是权威人士）对自己的期望来塑造行为和表现。
- **相互确保毁灭**: 双方都能将对方彻底毁灭的恐怖平衡，使得任何一方都不敢率先发动致命攻击。
- **眼镜蛇效应**: 针对某个问题制定的解决方案，由于动机设计不当，反而使得问题变得更加严重。
- **破窗理论**: 环境中的微小破坏如果不及时修复，就会释放出一种纵容的信号，诱发更多严重的破坏。
- **社会认同**: 当人们对不确定的情况感到犹豫时，往往会通过观察并模仿他人的行为来做决定。
- **科学方法**: 一套通过观察、提出假设、实验验证并根据结果不断修正认知的系统性探究体系。
- **科斯定理**: 只要交易成本为零且产权界定清晰，无论初始权益归谁，市场机制都能自发实现资源的最优配置。
- **稀缺**: 当你极度缺乏某样资源（如时间或金钱）时，大脑会被其俘获，借用未来资源救急而陷入越来越穷的死循环。
- **第一性原理**: 剥开事物的所有表象，回溯到最底层、颠扑不破的本源基础，然后从头开始重新推导演算。
- **算法**: 为解决特定问题或达成某个目标，而制定的一系列明确、详细且可重复执行的操作步骤。
- **纳什均衡**: 在非合作博弈中，所有人都不愿单方面改变自己策略以防收益受损的僵持状态。
- **线流图**: 将复杂系统中的变量和因果关系通过节点和箭头进行可视化，以寻找关键路径或瓶颈。
- **组织文化**: 一个群体在长期共存中内化并共同遵循的价值观、行为准则和潜在假设的总和。
- **群体思维**: 团队由于过度追求表面的和谐与一致，导致放弃了批判性思考，进而做出灾难性的错误决策。
- **肥尾分布**: 极端事件发生的概率远大于正态分布所预测的模型，世界的主宰往往是不对称的极端值。
- **自然选择**: 适应环境的特征被保留，不适应的特征被淘汰，揭示了系统在竞争中演化的底层逻辑。
- **蒙特卡洛模拟**: 通过大量的随机抽样和重复计算，来近似求解那些极其复杂、无法用解析法直接得出答案的问题。
- **蝴蝶效应**: 在特定的复杂动态系统中，初始条件的微小偏差，会沿着连锁反应被无限放大，最终引发极其庞大的后果。
- **认知失调**: 当个人的信念与现实、或信念与行为发生冲突时产生的心理痛苦，迫使人们去强行合理化自己的行为。
- **贝叶斯学派**: 不是去寻找绝对的真理，而是从一个初始信念出发，根据新出现的证据不断更新和修正概率。
- **贝叶斯定理**: 一个用来计算在得到新证据后，某事件发生概率应当如何精确更新的数学公式。
- **赌徒谬误**: 错误地认为由于某事件在过去发生的频率高于正常值，所以未来发生的概率就会降低。
- **过拟合**: 模型为了追求对历史训练数据的完美匹配，把偶然的噪音也当成了规律，导致完全丧失了对新情况的预测能力。
- **过滤气泡**: 算法根据用户的喜好个性化推荐内容，导致用户逐渐陷入只看得到同质化信息的认知茧房。
- **逆向选择**: 由于买卖双方的信息不对称，导致市场上的劣质商品反而将优质商品驱逐出局的现象。
- **道德风险**: 当一个人不需要承担自己行为的全部风险或代价时，他就会放纵自己不去防范风险甚至故意作恶。
- **邓宁-克鲁格效应**: 能力越低的人越容易对自己产生虚幻的优越感，而能力强的人反而常常低估自己。
- **零和**: 在封闭系统内进行的博弈，一方获取的收益必然意味着另一方的等额损失。
- **预期值**: 将事件所有可能发生的结果与其对应的概率相乘并求和，用以衡量长期的平均获益。
- **预测市场**: 汇聚大众资金通过交易事件发生概率的方式，来利用集体智慧极其准确地预测未来。
- **颠覆性创新**: 从市场边缘的低端或未消费领域切入，最终凭借技术迭代颠覆现有行业巨头的策略。
- **风险预防原则**: 凡有活动或政策对公众或环境有不可回复的损害威胁时，不得以缺乏科学证据为由推迟预防措施。
- **飞轮**: 初始启动极其艰难，但经过持续推动积蓄动能后，系统就能以难以阻挡的惯性高速自行运转。
- **马斯洛需求层次**: 人类的动机像金字塔一样由低到高逐级分布，只有当底层的基本需求满足后，才会追求更高层次的精神实现。
- **魔鬼辩护人**: 在团队决策时，被刻意指定去扮演唱反调、挑刺和证伪的角色，以此来粉碎盲目的群体一致性。
- **黑天鹅事件**: 极度罕见、完全出乎意料，一旦发生却能带来颠覆性巨大冲击的极端事件。
